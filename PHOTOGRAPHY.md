## Use and presentation

- The [Pexels License](https://www.pexels.com/license/) allows free commercial website use and modification without required attribution. Credits are included nonetheless. The images are used within the storefront, not resold as standalone images or used as logos.
- The Moroccan breakfast photograph by Ekaterina Kvelidze is CC BY-SA 4.0. Attribution, source and license are linked in the storefront. Responsive resizing / CSS cropping are the presentation changes; that photo and its adapted presentation remain under CC BY-SA 4.0. The website's code is separate from the photograph's license.
- Sugar Bear's chocolate milk photograph is released into the public domain by the photographer on its original Commons page.
- Photos illustrate the food or a known component. An American brunch is represented by pancakes, and the healthy brunch by a salmon/fromage bagel. The full pack contents remain exactly as written in the menu. Garnishes, extra dishes, quantities and serving vessels pictured are not added to the order or offered as new choices. The cake's specific flavor and salads' recipes are not inferred from stock photography. Chia pudding is explicitly identified on the combined chia/balboula card; it does not represent balboula.
- Brunch composé, Healthy Drink and Exotic Drink keep intentional typographic treatments because their compositions are unspecified. No unrelated dish, juice recipe or AI-generated product is used to fill that gap.

## Image delivery and optimization

Pexels images use compressed, explicitly sized CDN crops at 240 / 480 / 640 / 960 / 1280 px, with responsive `srcset` and layout-specific `sizes`. Wikimedia uses its standard thumbnail service at 960 / 1280 px. Uniform card proportions and declared dimensions reserve layout space. The hero loads eagerly at high priority; secondary images load lazily with asynchronous decoding. Thumbnails within format controls request smaller sizes. CSS positions crops around the food.

If a transformed image fails, the component retries the original source once, then displays a legible branded fallback without a broken-image icon. Neither loading nor a failed image blocks ordering. Photo hosts are preconnected; no stock API, API keys or image-generation service is required.

The current sandbox cannot download from these external hosts (DNS/network restriction), so there are **no locally cached food image binaries** and no claim that their live loading or visual crops was verified in a browser here. The application references the providers' actual image CDNs. `npm run test:e2e` performs live image checks in an unrestricted environment. Original source/license links remain in the manifest for later self-hosting or replacement with the client's own approved photographs.
